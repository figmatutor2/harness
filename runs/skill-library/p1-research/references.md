## 검색 조건

- 검색 키워드: "라이브러리"(화면 패턴), "검색 바, 칩"(컴포넌트), "카드, 칩" + 교육&도서, "프롬프트 복사"(문구), "난이도" + 교육&도서(문구), "다운로드 자료"(문구), "멤버십 전용" + 배지(문구), "템플릿" + AI(화면 패턴)
- 사용한 도구: search_ui_patterns / search_components / search_by_ocr_text

## 레퍼런스

### R1. Spotify — 내 라이브러리

- 링크: https://uibowl.io/name/Spotify?patterns=%EB%B6%81%EB%A7%88%ED%81%AC%C2%B7%EC%9C%84%EC%8B%9C%EB%A6%AC%EC%8A%A4%ED%8A%B8&patternName=%EB%9D%BC%EC%9D%B4%EB%B8%8C%EB%9F%AC%EB%A6%AC
- 화면 구성: 좌상단에 프로필 원형 + "내 라이브러리" 큰 제목, 우상단에 검색 아이콘과 + 아이콘. 제목 바로 아래 "플레이리스트 / 앨범 / 아티스트" 회색 채움 pill 칩이 가로로 나열됨. 그 아래 좌측 "최근" 정렬 토글, 우측 그리드/리스트 전환 아이콘. 본문은 좌측 정사각 썸네일 + 제목(굵게) + 유형·보조정보(회색 작은 글씨) 2줄 구성의 세로 리스트.
- 눈에 띄는 점: 콘텐츠 유형 필터(칩) → 정렬 → 목록 순서가 한 화면 상단에 압축돼 있어, 강의자료·다시보기·템플릿·스킬 카드를 "한곳"에서 유형별로 좁혀 보는 US-2 구조와 맞음. 검색은 아이콘으로 접어 두고 필요 시 펼치는 방식.

### R2. 레포브 — 라이브러리 (탐색)

- 링크: https://uibowl.io/name/%EB%A0%88%ED%8F%AC%EB%B8%8C?patterns=%ED%83%90%EC%83%89&patternName=%EB%9D%BC%EC%9D%B4%EB%B8%8C%EB%9F%AC%EB%A6%AC
- 화면 구성: "라이브러리" 굵은 제목 + 우측 검색 아이콘. 그 아래 텍스트 탭(캘린더/평점/타임라인/갤러리/장소/컬렉션)이 가로 스크롤되고 선택 탭은 검정 굵은 글씨 + 밑줄. 탭 아래 한 줄에 "평점 ∨", "날짜 ∨" 드롭다운 pill과 "전체 4"(검정 채움 선택), "책 1", "일상 1" 등 개수가 붙은 흰색 외곽선 pill 칩이 섞여 있음. 우측에 보기 비율 토글 아이콘. 하단은 흰 pill 형태의 플로팅 내비게이션 바.
- 눈에 띄는 점: 필터 칩에 항목 개수를 함께 붙여 결과 규모를 미리 알려 줌. 선택 칩은 검정 채움, 비선택은 흰 바탕 + 얇은 테두리로 흑백만으로 상태를 구분 — design.md의 흑백 pill 언어와 거의 일치.

### R3. 히로인스 — 검색 결과 (검색 바 + 카테고리 칩)

- 링크: https://uibowl.io/name/%ED%9E%88%EB%A1%9C%EC%9D%B8%EC%8A%A4?patterns=%EA%B2%80%EC%83%89&imgId=cmqg8jw3x0007lb042crdj7ju
- 화면 구성: 상단에 뒤로가기 + 회색 채움 둥근 검색 바(돋보기, 입력어, 우측 X 지우기). 아래 2분할 탭(쇼핑일기/상품), 선택 탭은 검정 밑줄. 그 아래 "전체(검정 테두리 강조) / 뷰티 / 식품 / 건강 / 생활 / 패션 / 기타" pill 칩이 가로 스크롤. 본문은 2열 이미지 카드 그리드, 카드 하단에 제목 2줄 + 작성자.
- 눈에 띄는 점: 검색어 입력 상태에서도 카테고리 칩이 유지돼 "검색 + 태그 필터"를 동시에 적용할 수 있음. 지우기(X) 버튼으로 검색 초기화가 쉬움.

### R4. 구글 제미나이 (Google Gemini) — 메모리 가져오기 (프롬프트 복사)

- 링크: https://uibowl.io/name/%EA%B5%AC%EA%B8%80%20%EC%A0%9C%EB%AF%B8%EB%82%98%EC%9D%B4%20(Google%20Gemini)?patterns=%EC%84%A4%EC%A0%95&imgId=cmto3vbn70039i804sl50i15e
- 화면 구성: 큰 제목 아래 원형 숫자 "1" + "다른 AI 제공업체와의 채팅에 이 프롬프트를 복사하세요" 단계 안내. 그 아래 연회색 둥근 박스에 프롬프트 본문이 여러 줄 표시되고 아래가 흐려지며 잘림. 박스 우측 하단에 흰 바탕 외곽선 pill "복사" 버튼(복사 아이콘 + 라벨)이 겹쳐 있음. 이어서 "2 여기에 대답 붙여넣기" 입력 영역이 이어지는 번호형 단계 구성.
- 눈에 띄는 점: 긴 프롬프트를 페이드로 잘라 미리보기하고, 복사 버튼을 박스 안 우하단에 고정해 "읽기 → 한 번에 복사" 동선이 짧음. 번호 단계로 사용 순서를 보여 주는 구조가 스킬 카드의 "사용 순서" 항목에 그대로 대응.

### R5. 열품타 — AI 선택 (도구별 프롬프트 복사)

- 링크: https://uibowl.io/name/%EC%97%B4%ED%92%88%ED%83%80?patterns=AI&imgId=cmq95vsnf001nla04n1hee6dq
- 화면 구성: 상단 "AI 선택" 타이틀 아래 회색 트랙 위 세그먼트 탭 "ChatGPT / Claude / Gemini"(선택은 흰 칸). 흰 카드 안에 검정 원형 숫자 "1" + "텍스트 복사하기" 굵은 제목, 보조 설명, 테두리 박스 안에 "연결 프롬프트" 라벨과 프롬프트 텍스트. 카드 하단에 전폭 주황 채움 CTA "텍스트 복사하고 다음으로". 그 아래 비활성 회색 카드 "2 ChatGPT 열기".
- 눈에 띄는 점: 사용 도구를 세그먼트로 먼저 고르면 그 도구용 프롬프트가 보이는 구조 — 카드의 "사용 도구" 필드를 행동으로 연결. 복사와 다음 단계 이동을 한 버튼에 묶음.

### R6. Onevoca — 라이브러리 (단어 세트 광장)

- 링크: https://uibowl.io/name/Onevoca?patterns=%ED%83%90%EC%83%89&imgId=cm2lp500l000cju0cs2kpu44t
- 화면 구성: "라이브러리" 제목 + 2분할 탭(단어 세트 광장/스터디그룹). "꼭 외워야 하는 단어" 섹션 제목 + 우측 "더보기 >", 그 아래 연회색 정사각 카드 2개 가로 배치. "인기 단어 세트 모음" 섹션에 "7일(보라 채움 선택) / 1달 / 1년 / 전체" pill 칩, 그 아래 연회색 채움 둥근 카드 리스트 — 카드 안 상단 작성자 줄, 굵은 세트명, 하단에 "66번 다운로드 됐어요" 보조 문구, 우상단 요일 표시.
- 눈에 띄는 점: 그림자 없이 연회색 채움만으로 카드를 구분하고, 카드 하단에 다운로드 수 같은 메타 정보를 한 줄로 둠. 섹션별 "더보기"로 큐레이션 영역과 전체 목록을 나눔.

### R7. 무디 Moodee — 프리미엄 멤버십 전용 콘텐츠 잠금

- 링크: https://uibowl.io/name/%EB%AC%B4%EB%94%94%20Moodee?patterns=%EC%83%81%EC%84%B8%EC%A0%95%EB%B3%B4%20%28PDP%29&imgId=cmsd9wl140015l704spkftlpa
- 화면 구성: 상단 일러스트 헤더에 "3분 소요" 작은 배지 + 흰색 제목·부제. 본문 첫 문단만 보인 뒤 아래로 흐려지며 끊김. 가운데 연보라 자물쇠 아이콘, "프리미엄 멤버십 전용 컨텐츠입니다." 굵은 문구 + 회색 안내 한 줄, 하단 전폭 그라데이션 pill CTA "프리미엄 멤버십 보러가기".
- 눈에 띄는 점: 잠긴 콘텐츠도 앞부분은 보여 주고(미리보기) 잠금 사유를 한 문장으로 명시. 권한이 없는 사용자에게 무엇이 잠겼는지 알게 함.

### R8. 디맨드 — 현직자 리뷰 (멤버십 전용 배지 + 부분 잠금)

- 링크: https://uibowl.io/name/%EB%94%94%EB%A7%A8%EB%93%9C?patterns=%EB%A6%AC%EB%B7%B0&imgId=cmtkpsyxa000zk004fjixk4e1
- 화면 구성: 섹션 제목 "현직자 리뷰" 오른쪽 끝에 회색 채움 작은 사각 배지 "멤버십 전용". 요약 점수 카드는 공개, 그 아래 항목별 평점 카드 내부 하단에 작은 자물쇠 아이콘 + "현직자 57명의 검증된 정보가 잠겨 있어요" 문구와 연파랑 버튼. 화면 최하단에 전폭 파랑 CTA와 텍스트 링크.
- 눈에 띄는 점: 권한 표시를 제목 옆 작은 배지로 먼저 알려 주고, 공개 영역과 잠긴 영역을 같은 카드 안에서 구분. 목록 카드에 권한 배지(무료/유료/코호트)를 다는 방식의 근거.

- 눈에 띄는 점: 난이도·기간 같은 메타를 카드 우상단 작은 배지로 모아 제목과 분리. 카테고리를 "> "로 이어 쓴 경로 표기로 계층을 짧게 보여 줌.

### R10. 리멤버 — 프로필 (PDF 다운로드 행)

- 링크: https://uibowl.io/name/%EB%A6%AC%EB%A9%A4%EB%B2%84?patterns=%EB%A7%88%EC%9D%B4%ED%8E%98%EC%9D%B4%EC%A7%80&imgId=cm40lcqie000eia0clwjlqid0
- 화면 구성: 프로필 입력 섹션들(점선 테두리 "+ 추가" 박스) 아래, 구분선으로 나뉜 액션 행 목록. 첫 행 "↓ 내 프로필 PDF로 다운로드"가 다운로드 아이콘 + 주황 텍스트로 표시되고, 이어서 "프로필 열람 차단 회사 설정", "프로필이란?" 행이 같은 스타일로 나열.
- 눈에 띄는 점: 다운로드를 버튼이 아닌 아이콘 + 라벨 행으로 두어 파일 형식(PDF)을 라벨에 직접 밝힘. 파일 형식을 미리 알려 주는 방식은 스킬 파일 다운로드 버튼 라벨에 참고할 만함.
