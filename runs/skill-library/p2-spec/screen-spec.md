## 목적

하이서가 만든 검증된 프롬프트와 스킬 파일(prd.md §6-3)을 구조화된 카드 목록으로 한곳에 모아, 멤버가 "지금 필요한 스킬"을 검색·태그 필터로 빠르게 좁히고 카드 한 장에서 바로 복사하거나 파일을 내려받게 한다.

- 해결하는 문제: 프롬프트와 스킬 파일이 강의자료·디스코드 등 여러 곳에 흩어져 있어 다시 찾기 어렵고, 난이도·사용 도구·권한을 열어 보기 전에는 알 수 없다.
- 사용자가 얻는 결과: 목록 단계에서 난이도·사용 도구·권한을 한눈에 보고, 카드를 열면 사용 순서대로 따라 쓴 뒤 한 번의 탭으로 복사하거나 내려받는다. 권한이 없는 카드는 무엇이 잠겼는지와 그 이유를 안다.
- 화면 위치: 하단 탭 "자료실" 소속 목록 화면 1개. 카드 상세, 잠금, 예시 결과 바텀시트는 이 화면의 상태로 다룬다(아래 "상태" 참고).

## 연결 유저스토리

- US-2: 유료 멤버로서 강의자료·다시보기·템플릿·스킬/프롬프트 카드를 한곳에서 찾아 복사하거나 내려받는다. (핵심)
- US-1: 무료 학습자로서 공개 학습자료를 카테고리별로, 유료 자료는 미리보기로 둘러본다. (보조: 무료 회원은 무료 카드를 사용하고, 유료·코호트 전용 카드는 앞부분 미리보기와 잠금 사유만 본다. prd.md §7-2 "샘플 프롬프트 사용 · 유료 자료 미리보기")

## 상태

- 로딩: 검색 바·칩은 그대로 두고, 카드 자리에 canvas-soft 스켈레톤 카드 3장을 표시
- 기본(목록): "전체" 칩 선택, 검색어 없음, 최신 업데이트순 카드 리스트
- 태그 필터 적용: 칩 1개 선택 → 결과 요약 문구와 목록 갱신("자동화 · 스킬 6개")
- 검색 입력 중: 검색 바 활성(커서, 지우기 X 표시), 칩 선택 유지, 입력에 맞춰 목록이 좁혀짐
- 검색 결과: 검색어 + 칩 조건을 함께 적용한 목록. 결과 요약 "'회의록' 검색 결과 3개"
- 결과 없음: 목록 자리에 "조건에 맞는 스킬이 없어요" + 보조 문구 "다른 검색어나 태그를 선택해 보세요" + 외곽선 pill "필터 초기화"
- 오류: "스킬 목록을 불러오지 못했어요" + 외곽선 pill "다시 시도"
- 카드 상세 · 열림: 권한이 있는 카드. 프롬프트 박스·복사 버튼·파일 다운로드·예시 결과·관련 미션 모두 사용 가능
- 카드 상세 · 잠김: 권한이 없는 카드(무료 회원이 멤버십 카드를 열거나, 해당 기수가 아닌 멤버가 코호트 전용 카드를 연 경우). 앞부분만 공개하고 프롬프트/파일 블록은 흐림 + 자물쇠 + 사유 한 줄
- 프롬프트 전체 보기: 박스의 페이드가 풀리고 전체 프롬프트 표시, 링크 라벨이 "접기"로 바뀜
- 복사 완료: "복사" 버튼 라벨이 잠시 "복사됨"으로 바뀌고 토스트 "복사했어요" 표시
- 다운로드 중 / 완료 / 실패: 행 우측이 진행 표시 → "다운로드를 시작했어요" 토스트 → 실패하면 "다운로드하지 못했어요 · 다시 시도"
- 예시 결과 바텀시트 열림: 전체 예시 결과 표시, 닫기 또는 아래로 밀면 상세로 복귀
- 상태 전이
  - 로딩 → 기본 → (칩 선택) 태그 필터 적용 → (검색어 입력) 검색 입력 중 → 검색 결과 / 결과 없음 → (필터 초기화 또는 X) 기본
  - 로딩 → 오류 → (다시 시도) 로딩
  - 기본 → (카드 탭) 카드 상세 · 열림 또는 카드 상세 · 잠김 → (뒤로) 이전 목록 상태(검색어·칩 유지)
  - 카드 상세 · 열림 → (복사) 복사 완료 → 카드 상세 · 열림
  - 카드 상세 · 열림 → (다운로드) 다운로드 중 → 완료 / 실패
  - 카드 상세 · 열림 또는 잠김 → (예시 결과 전체 보기) 예시 결과 바텀시트 → (닫기) 카드 상세
  - 카드 상세 · 열림 → (관련 미션 행 탭) 내 학습 탭의 미션 화면으로 이동
